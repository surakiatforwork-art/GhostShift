# GhostShift Native (Android)

แอปพลิเคชัน Android สำหรับ GhostShift (พัฒนาโดย PHANToM) สร้างขึ้นใหม่แบบ Native (Kotlin + Compose) เพื่อแทนที่เวอร์ชัน HTML เดิม โดยยังคงกฎการทำงานและหน้าตา (Mint Light Theme) ไว้อย่างครบถ้วน

## 📋 ฟีเจอร์หลัก
- **Native Experience**: ไม่ใช้ WebView, เร็วและลื่นไหลกว่าเดิม
- **Exact Timer**: ระบบนับเวลา 9 ชม. 10 นาที ที่แม่นยำ พร้อมกฎ Unlock (OUT-20)
- **Schedule Calculation**: คำนวณเวลา Next/Countdown ตามกฎ Gap (IN: 3-25m, OUT: 4-30m)
- **Local Alarm**: แจ้งเตือนเมื่อถึงเวลาแม้ปิดแอป (ใช้ AlarmManager)
- **Photo Management**: ถ่ายรูป/เลือกรูป, Resize/Crop อัตโนมัติ, Export ลงเครื่อง (Downloads/Pictures)

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose (Material3)
- **Architecture**: MVVM + Clean Architecture principles
- **Local Data**: Room (Metadata), DataStore (Preferences), Files (Images)
- **System**: AlarmManager, NotificationManager, CameraX, WorkManager

## 📱 Permissions
แอปพลิเคชันต้องการสิทธิ์ดังนี้:
1.  **CAMERA**: สำหรับถ่ายรูปงาน (บังคับ)
2.  **POST_NOTIFICATIONS** (Android 13+): สำหรับแจ้งเตือนเมื่อครบเวลา (บังคับเพื่อให้ทราบเวลา)
3.  **SCHEDULE_EXACT_ALARM** (Android 12+): เพื่อให้การแจ้งเตือนตรงเวลาเป๊ะ (ถ้าปิด จะแจ้งเตือนอาจคลาดเคลื่อน)
4.  **READ_MEDIA_IMAGES** / **READ_EXTERNAL_STORAGE**: สำหรับเลือกรูปจาก Gallery (ถ้าไม่ใช้ Photo Picker)

## 🏗 วิธี Build (Local)
1.  เปิดโปรเจกต์ด้วย Android Studio Ladybug หรือใหม่กว่า
2.  รอให้ Gradle Sync เสร็จสิ้น
3.  เลือก Build Variant เป็น `release` หรือ `debug`
4.  Run ลงเครื่องจริงหรือ Emulator (แนะนำ API 33+)

## 🚀 วิธี Build (Codemagic CI)
โปรเจกต์รองรับการ Build ผ่าน Codemagic ด้วยไฟล์ `codemagic.yaml`
1.  เชื่อมต่อ Repo กับ Codemagic
2.  ตั้งค่า Environment Variables (ถ้าต้องการ Signing):
    - `CM_KEYSTORE`: ไฟล์ keystore (base64 encoded)
    - `CM_KEY_ALIAS`: ชื่อ alias
    - `CM_KEY_PASSWORD`: รหัสผ่าน key
    - `CM_KEYSTORE_PASSWORD`: รหัสผ่าน keystore
3.  เลือก Workflow "Android Release" หรือ "Android Debug"
4.  รับไฟล์ `.apk` ได้ทันที

## ⏳ กฎเวลาและเงื่อนไข (Summary)
- **Timer 9:10**: เริ่มนับ 9 ชม. 10 นาที
- **Lock/Unlock**:
    - เริ่มต้นจะ **Locked** (รีเซ็ตไม่ได้)
    - ปลดล็อคเมื่อ: มีรูปคู่ต่อเนื่อง (IN-n, OUT-n) ถึง **OUT-20** เป็นอย่างน้อย และทำการ **Export** รูป OUT-20 นั้นแล้ว
- **Export**: การกด Download คือการ Export ไฟล์ลงเครื่อง และถือเป็นการ "Check-point" เวลา (Mark downloadedAt)
